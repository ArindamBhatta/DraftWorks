# DraftWorks

## 1. Local-First Drawing

Your drawing is stored in the browser's local storage as you work — so if you close the browser, your data is still there. You can also export your drawing to your computer at any time. You can import an AutoCAD drawing into DraftWorks and continue drafting on it here.

## 2. No More Save Headaches

No more manually saving your work. DraftWorks saves automatically after every change, just like Google Docs. If you close your browser, your data is already saved.

## 3. UI Simplification

AutoCAD has several nested commands. For example: press `C`, then choose `2P` or `3P`, then specify a radius or diameter. In DraftWorks, all the steps of a nested command are shown directly in the UI, so a user who doesn't know — or has forgotten — the command sequence can still complete it easily. Every command is also accessed the same, consistent way.

## 4. Proactive UI

Unit setup and dimension setup are asked upfront by the UI. If you tell DraftWorks it's a structural drawing, it sets up production-level layers accordingly — for example, a beam layer, a column layer, and a beam reinforcement layer.

## 5. AI Implementation

Tell DraftWorks what you want — your plot area, your specifications — and it can ask follow-up questions before drawing the plan. If you change your requirements afterward, it redesigns the drawing to match. The same approach works for other elements, such as drawing a pile.
